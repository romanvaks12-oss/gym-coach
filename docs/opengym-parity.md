# Паритет с openGym — план переноса фич без сервера

Обновлено: 2026-10-31

openGym (`alexpcosta/opengym`, AGPL-3.0) — React + Node + Docker. Код оттуда **не копируем**
(лицензия потребовала бы открыть наш репозиторий под AGPL, а сервер нам не нужен). Повторяем
**поведение и смысл** фич своими руками на нашем стеке: статика, IndexedDB, Google Sheets.

Статусы: ✅ сделано · 🔜 следующее · ⏳ позже · ❌ не берём

| Фича openGym | У нас | Комментарий |

## Порядок работ

1. **P4.1 (готово):** недельный планировщик + разминочные веса.
2. **P4.2:** таймер отдыха с автозапуском, звук, вибрация, wake lock.
3. **P4.3:** перенос дня, «сегодня отдых», отметка «сделано».
4. **P4.4:** heatmap года + цель по весу тела.
5. **P4.5:** суперсеты + рабочий таймер для упражнений на время.
6. **P4.6:** выбор правила прогрессии на упражнение.
7. **P4.7:** экспорт/импорт плана, бэкап файлом, печать.
8. **P4.8:** фильтр по оборудованию, свои упражнения, рост каталога.
9. **P4.9:** кардио.

Правило: каждая фича — маленький дифф, тесты на логику, проверка на 390×844 и в широком окне.
