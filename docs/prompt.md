# Промт-бриф: Gym Coach

> Этот файл — исходное ТЗ. Его можно целиком отдавать агенту как контекст.
> Раздел «Уточнения» дополняется по мере принятия решений.

## 1. Роль агента

Ты — продуктовый инженер и тренер-методист в одном лице. Пишешь весь код сам, решения объясняешь
простым языком (заказчик не разработчик). Предлагаешь минимум технологий, следишь, чтобы всё
оставалось бесплатным и работало с iPhone.

## 2. Задача

Личный помощник по силовым тренировкам. Пользователь приходит в зал, за 30 секунд заполняет бриф
о самочувствии, получает готовый план на сегодня (упражнения, подходы, повторения, вес), ведёт
тренировку по подсказкам, фиксирует каждый подход, а система копит данные и показывает прогресс.

Один пользователь. Показывает данные только ему. Мобильный экран — основной.

## 3. Ключевой сценарий (must have)

1. **Бриф** (≤ 30 сек, крупные кнопки):
   - сон (1–5), энергия (1–5), стресс (1–5);
   - болезненность по группам мышц (0–10): ноги, грудь, спина, плечи, руки, пресс;
   - сколько времени есть: 30 / 45 / 60 / 90 мин;
   - что болит/мешает (свободный текст, опционально).
2. **План.** Система выдаёт 1–3 варианта тренировки с короткой причиной у каждого
   («грудь свежая, ноги ещё болят → жим сегодня»). Пользователь выбирает.
3. **Ведение.** Экран тренировки: текущее упражнение, целевые подходы × повторения, вес,
   подсказка «на что смотреть» (техника), таймер отдыха. После каждого подхода — вес, повторы,
   сложность 1–10.
4. **Итог.** Сохранение тренировки, краткая сводка (тоннаж, подходы, средний RPE), отметка веса тела.
5. **Аналитика.** Графики: оценка 1ПМ по ключевым упражнениям, тоннаж по неделям, подходы по
   группам мышц, вес тела, частота тренировок. Таблицы: история подходов по упражнению, личные рекорды.

## 4. Логика плана — сначала правила, потом ИИ

Основа — детерминированный движок (объяснимый, бесплатный, работает офлайн):

- **Readiness** = f(сон, энергия, стресс, средняя болезненность) → 0–100.
  `< 40` → разгрузка/лёгкий день; `40–70` → объём −20…30 %; `> 70` → план как есть.
- **Болезненность**: `≥ 7` — группу не грузим; `4–6` — объём этой группы вдвое; `≤ 3` — норма.
- **Недельный объём** по группам (рабочие подходы): новичок 8–12, средний 12–18, опытный 16–22.
  Движок не даёт превысить верхнюю границу и добирает отстающие группы.
- **Прогрессия — двойная**: попал в верх диапазона повторов во всех подходах при RPE ≤ 8 →
  следующий раз +2,5 % веса (или +1–2,5 кг) и сброс повторов вниз.
- **Шкала сложности 1–10 → RIR**: 10 = отказ, 8 = 2 в запасе. Целевой RPE 7–9 на рабочих подходах.
- **Восстановление**: одна и та же группа — не чаще, чем раз в 48 ч (крупные — 72 ч).
- **Разгрузка** каждые 5–6 недель или при падении результатов 2 недели подряд.
- **1ПМ (оценка)** = вес × (1 + повторы / 30). Тренд смотрим по 3–4 неделям, не по одной тренировке.
- **Безопасность**: острая/стреляющая боль, суставы, головокружение → стоп-сигнал и совет к врачу.
  Приложение не ставит диагнозы и не заменяет тренера.

ИИ подключается сверху и **не обязателен для работы**:
- объяснить план человеческим языком и ответить на вопросы («почему так мало ног?»);
- предложить план при нестандартной ситуации (травма, отпуск, только гантели);
- разобрать тренировку и дать 2–3 замечания.
Если ИИ недоступен (нет сети, кончилась квота) — приложение работает на правилах.

## 5. Данные

Сущности (имена — латиницей):

- `exercise`: id, name, primaryMuscle, secondaryMuscles[], equipment, pattern (жим/тяга/присед/...),
  isCompound, techniqueCues[] (2–3 подсказки), isUnilateral.
- `workout`: id, date, brief{...}, readiness, chosenPlanId, status, durationMin, notes.
- `setLog`: id, workoutId, exerciseId, setIndex, weight, reps, rpe, isWarmup.
- `bodyMetric`: date, weightKg, waistCm(опц.).
- `plan` / `planItem`: шаблон плана, порядок упражнений, целевые подходы/повторы/RPE.
- Каталог упражнений — стартовый JSON на 40–60 упражнений (база + зал с тренажёрами).

Требования: экспорт/импорт всех данных в JSON-файл, версия схемы, авто-бэкап перед миграцией.

## 6. Ограничения

- Бесплатно: статический хостинг (GitHub Pages) и/или free tier serverless. Без карты и без VPS.
- iPhone Safari первым делом; «Добавить на экран Домой», работа офлайн в зале (плохой интернет).
- Крупные тач-таргеты (≥ 44 px), ввод веса/повторов одной рукой, тёмная тема.
- Никаких аккаунтов, соцфункций, рекламы, аналитики.
- Простой стек: чем меньше файлов и зависимостей, тем лучше. Сборка — только если реально нужна.

## 7. Фазы

| Фаза | Результат | Критерий готово |
|------|-----------|-----------------|
| P0 | Скелет приложения, навигация, локальное хранилище, каталог упражнений | Открывается на iPhone, упражнения листаются, данные не теряются после перезагрузки |
| P1 | Бриф → правила → 1–3 плана, ведение тренировки, таймер отдыха | Тренировка полностью проводится и сохраняется за 1 сеанс |
| P2 | Аналитика: 1ПМ, тоннаж, объём по группам, вес тела, история подходов | Все цифры считаются из сохранённых данных, есть тесты на формулы |
| P3 | ИИ-слой: объяснение плана, чат, разбор тренировки | Работает без ИИ (fallback), ключ не в репозитории |
| P4 | Бэкап/синк между устройствами (если понадобится) | Экспорт/импорт проверен на реальных данных |
