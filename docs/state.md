# Состояние проекта

Обновлено: 2026-10-26

## Сейчас

P1 + правки по логике готовы, репозиторий на GitHub, деплой на Pages через Actions.
Сделано после разбора с «фитнес-тренером»:
- планировщик — сплит-скелет (всё тело / верх / низ) + фильтр восстановления: крупные группы
  (ноги, спина, широчайшие, грудь, плечи) не грузим 2 дня, мелкие — 1; болезненность 7–10 исключает
  группу; бонус ротации `upper → lower`; тип прошлой тренировки в `meta.lastDay`, «всё тело» —
  запасной вариант при наличии истории (ADR-008);
- убраны разминочные подходы из экрана тренировки, в лог идут только рабочие; вес тела в брифе
  сохраняется в `body`; подтягивания 2–3 повтора × максимум 3 подхода, прогрессия по повторам,
  тоннаж = (вес тела + доп. вес) × повторы; планка и прогулка фермера — в секундах (ADR-009);
- карта мышц перерисована: антропоморфный силуэт (голова, шея, торс с талией, руки, ноги, стопы),
  детализированные группы (дельты, верх/низ груди, пресс 6 сегментов + косые, крылья широчайших,
  разгибатели, трицепс/бицепс бедра по головкам, ягодицы) — ADR-007 обновлён;
- план-таблица не расползается на 390 px (`table-layout: fixed`);
- записанный подход можно **исправить или удалить**: «правка» в списке подходов → меняются вес,
  повторы и RPE, номер подхода сохраняется; удаление перенумеровывает остальные (ADR-010);
- защита от опечаток: жёсткие пределы (вес ≤ 400 кг, повторы 1–100, время ≤ 1800 с, RPE 1–10,
  дробные повторы запрещены) и мягкое предупреждение «вес резко больше прошлого» с подтверждением
  вторым нажатием — 112 вместо 12 больше не улетает в базу молча;
- 56 тестов зелёные (27 логики + 28 стресс/границ + 1 новый), `typecheck` и `build` чистые.
  Стресс-набор нашёл реальный баг: при болезненности 10/10 по всем группам возвращался пустой план
  вместо «день отдыха» — исправлено в `plan.ts`.

## Ручная проверка

`npm run dev` → `http://127.0.0.1:5173`, вьюпорт 390×844:
бриф с весом тела → «Собрать план» → два варианта (низ/верх и разумный порядок) →
«Начать» → «Записать подход» → таймер → «Завершить» → сводка.
Повторный бриф с болезненностью 7+ убирает упражнения на эту группу; после завершения тренировки
следующий план не предлагает тот же день верха/низа.

Правка и защита от опечаток (проверено на проде):
записать подход 12 кг × 8 → ввести 112 → «Записать подход» показывает «Вес 112 кг резко больше
прошлого (12 кг) — похоже на опечатку. Всё верно?», кнопка меняется на «Всё верно, записать» →
нажать «правка» у второго подхода → поменять 112 на 22 → «Сохранить изменения» (номер подхода и
список не дублируются) → «Удалить подход» убирает строку и перенумеровывает остальные →
«Следующее упражнение →» и «← пред.» возвращают к предыдущему упражнению с его подходами.

Вёрстку без кликов удобно смотреть на `/preview.html` (страница только для dev, в сборку не входит):
план, экран тренировки и карта мышц сразу. Быстрые сценарии: `?demo=warn` (12 → 112 →
предупреждение) и `?demo=edit` (записан подход, открыта правка).
