# Состояние проекта

Обновлено: 2026-10-25

## Сейчас

P0 собран и проверен в браузере: каркас Vite + React + TS, тёмная тема, 4 экрана через нижние табы,
каталог на 58 упражнений с поиском и фильтром по группам, IndexedDB (`workouts`/`sets`/`body`/`meta`),
экспорт JSON, экран настроек синка, манифест + service worker, workflow GitHub Pages.
`npm run typecheck` и `npm run build` зелёные, ошибок в консоли нет.

## Ручная проверка P0

`npm run dev` → `http://127.0.0.1:5173`. Проверено: табы переключаются, каталог фильтруется
(«Все» → 58, поиск и чипы работают), счётчики в «Прогрессе» читают IndexedDB, консоль чистая.
На iPhone: открыть деплой в Safari → «Поделиться» → «На экран Домой», проверить, что нет зума
и горизонтального скролла.
