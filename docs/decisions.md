# Решения (ADR)

Формат: `## ADR-NNN — Название` + Контекст / Решение / Последствия / Дата.
Статус: `proposed` | `accepted` | `superseded`.

## ADR-001 — Формат приложения: PWA / бот / таблица

Статус: proposed. Контекст: пользователь не разработчик, хочет бесплатно, ввод с телефона в зале,
любит таблицы и графики. Решение: ожидает ответа.

## ADR-002 — Где живут данные

Статус: proposed. Варианты: IndexedDB локально + файловый бэкап / Supabase free / Google Sheets.

## ADR-003 — Роль ИИ

Статус: proposed. Базовая логика — детерминированные правила; ИИ — объяснения и нестандартные случаи.
