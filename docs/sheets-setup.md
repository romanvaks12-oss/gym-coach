# Google Sheets как зеркало данных — настройка за 10 минут

Таблица — это **зеркало**, а не основной источник: приложение всегда работает от данных
на телефоне и без интернета. Таблица нужна, чтобы данные не потерялись при смене телефона,
были видны с компьютера и не зависели от одного браузера.

Что нужно: Google-аккаунт и 10 минут. Платить ничего не нужно, карта не нужна.

---

## Шаг 1. Создать таблицу

1. Зайди на [sheets.new](https://sheets.new) — создастся пустая таблица.
2. Назови её, например «Gym Coach».
3. Листы создавать руками не надо — скрипт сделает их сам
   (`workouts`, `sets`, `body`, `_meta`).

## Шаг 2. Открыть редактор скрипта

1. В таблице: **Расширения → Apps Script**.
2. Откроется вкладка с файлом `Код.gs` (или `Code.gs`).
3. Выдели всё, что там есть (`Ctrl+A`), и удали.
4. Открой в проекте файл `integrations/apps-script/Code.gs`, скопируй его целиком и вставь
   в редактор.
5. Нажми **💾 Сохранить** (или `Ctrl+S`).

## Шаг 3. Придумать токен

Токен — это длинный пароль, которым приложение доказывает таблице, что оно «своё».
Его можно придумать прямо в приложении: **Настройки → «Придумать токен»** → скопировать.

В `Code.gs` найди строку:

```js
const TOKEN = "PASTE_YOUR_TOKEN_HERE";
```

Замени текст в кавычках на свой токен (кавычки оставь):

```js
const TOKEN = "gc-abc123xyz";
```

Сохрани файл. **Пока токен не заменён, таблица отвечает `token_not_configured`** — это защита
от случайно открытого пустого скрипта.

## Шаг 4. Развернуть как веб-приложение

1. Справа вверху: **Развернуть → Новое развёртывание**.
2. Слева выбери тип **Веб-приложение** (значок шестерёнки → «Веб-приложение»).
3. Заполни:
   - **Описание** — «Gym Coach API» (любое);
   - **Запуск от имени** — **Я** (твой аккаунт);
   - **У кого есть доступ** — **Все** (Anyone). Без этого телефон не сможет отправить данные.
4. **Развернуть**. Google попросит разрешения:
   **Авторизоваться → выбрать аккаунт → «Дополнительные настройки» → «Перейти к проекту
   (небезопасно)» → Разрешить**. Это нормально: скрипт твой, доступ он просит только к этой
   таблице.
5. Скопируй **URL веб-приложения**. Он заканчивается на `/exec`.

> Ссылка вида `https://script.google.com/macros/s/AKfy…/exec` — это и есть адрес API.
> Не путай с URL редактора скрипта.

## Шаг 5. Подключить в приложении

1. Открой Gym Coach → **Настройки**.
2. Вставь **URL синка** (тот, что заканчивается на `/exec`).
3. Вставь **Токен** — тот же, что в `Code.gs`.
4. Нажми **«Проверить связь»**. Должно появиться «Связь есть — таблица отвечает».
   - `Неверный токен` → токен в приложении и в `Code.gs` разный;
   - `В Apps Script не задан TOKEN` → шаг 3 не выполнен;
   - `Ответ не JSON` → в URL не `/exec` или доступ не «Все».
5. Нажми **«Слить сейчас»** — данные уедут в таблицу, а из таблицы приедут обратно.

Всё. Дальше приложение отправляет тренировку **само** после «Завершить тренировку»,
если синк настроен и есть интернет. Нет интернета — данные остаются в телефоне и уйдут
при следующем синке. Кнопка «Отправить ещё раз» есть на экране после тренировки.

## Что появится в таблице

| Лист | Что внутри |
| --- | --- |
| `workouts` | по строке на тренировку: дата, готовность, длительность, план |
| `sets` | по строке на рабочий подход: упражнение, вес, повторы, RPE |
| `body` | вес тела по датам |
| `_meta` | версия схемы и время последнего синка |

Первая строка каждого листа — заголовки, они нужны скрипту. **Не переставляй колонки
и не переименовывай листы** — скрипт перестанет их находить.

Если листов нет (например, таблица совсем новая), в таблице появится меню
**«Gym Coach → Подготовить листы»** — оно создаст всё с правильными заголовками.

## Чего синк не делает

- **Не удаляет строки.** Удалил подход в приложении — в таблице строка останется.
  Это защита от потери данных: таблица — архив. Удалить можно руками.
- **Не решает конфликты по-умолчанию.** Если одну и ту же запись поменяли на двух
  устройствах, побеждает более свежая правка. Запись, которая ещё не ушла с телефона,
  всегда главнее серверной.
- **Не требует интернета для тренировки.** Сеть нужна только на этапе обмена.

## Безопасность — коротко

- В репозитории **нет** ни URL, ни токена: они хранятся в памяти твоего телефона
  (`localStorage`) и в скрипте твоей таблицы.
- Токен = доступ к таблице. Никому его не показывай и не вставляй в чаты.
- Если токен утёк: поменяй `TOKEN` в `Code.gs`, **разверни новую версию**
  (Развернуть → Управление развёртываниями → ✏️ → Новая версия) и вставь новый токен
  в приложении.
- В таблице лежат твои тренировки и вес. Доступ к ней — как к любому Google-документу:
  только у аккаунта, под которым она создана.

## Если что-то сломалось

| Симптом | Что делать |
| --- | --- |
| «Сервер не ответил за 20 секунд» | проверь интернет, открой URL в браузере — должен вернуться JSON с `ok` |
| `forbidden` | токен не совпадает |
| `unknown_action` | в таблице старый `Code.gs` — вставь новый и разверни новую версию |
| Данные не появляются | нажми «Слить сейчас», затем обнови таблицу (Google кэширует вид) |
| После смены токена ничего не работает | нужно **новое развёртывание**, правка файла сама по себе не обновляет URL |

Проверка в браузере без приложения (подставь свои значения):

```
https://script.google.com/macros/s/…/exec?action=ping&token=ТВОЙ_ТОКЕН
```

Ответ `{"ok":true,...}` — сервер жив. `{"ok":false,"error":"forbidden"}` — токен не тот.
