# Данные и аналитика

## Сущности (источник истины — `src/types.ts`)

```
exercise   id, name, primaryMuscle, secondaryMuscles[], equipment, pattern,
           isCompound, isUnilateral, cues[]
workout    id, date (YYYY-MM-DD), readiness, durationMin, planId, notes, createdAt, updatedAt
brief      workoutId, sleep 1-5, energy 1-5, stress 1-5, soreness{muscle:0-10}, minutes, painNote
setLog     id, workoutId, exerciseId, setIndex, weight (кг, 0 для тела), reps, rpe 1-10, isWarmup
bodyMetric date, weightKg, waistCm?
```

Правила: `date` — локальная дата пользователя (не UTC-сдвиг!), вес — килограммы,
дробные шаги 0,5 кг допустимы, `isWarmup` исключается из аналитики.

## Формулы

- **Тоннаж** тренировки: `Σ weight × reps` по рабочим подходам.
- **Оценка 1ПМ (Epley)**: `weight × (1 + reps / 30)`. Показывать как «≈1ПМ», не как факт.
- **Лучший подход** упражнения за период: максимум `e1rm`.
- **Неделя**: ISO-неделя (пн–вс) по локальной дате. Недельные агрегаты: тоннаж, подходы по группам,
  число тренировок, средний RPE.
- **Тренд**: сравниваем медиану e1RM за последние 2 недели с медианой за предыдущие 2.
  Разница < 2 % — «плато», рост — «прогресс», падение — «откат» (не паниковать, смотреть 3–4 недели).
- **Личный рекорд**: новый максимум e1RM для упражнения, если он выше прежнего более чем на 1 %.

## Как считать правильно

- Агрегация только по сохранённым данным, без «магии» в UI: все цифры — из `src/core/analytics.ts`.
- Никаких расчётов на лету по всей истории при каждом рендере: мемоизируем по `(exerciseId, period)`.
- Пустые состояния честные: «нужно 2 недели данных», а не «0 %».
- Графики: 7–30 точек максимум, раз в неделю, без сглаживания, которое врёт.
- Часовой пояс: одна функция `todayLocal()`, `weekStart()`. Никаких `new Date("2026-10-25")` без TZ —
  это UTC-полночь и сдвиг на день.

## Миграции

- `schemaVersion` в метаданных IndexedDB. При росте версии — авто-бэкап JSON в файл и только потом миграция.
- Миграции — линейные функции `v1→v2`, `v2→v3`. Старые данные не удаляем, поля только добавляем.
- Импорт чужого/старого JSON: валидация, отчёт «столько строк принято, столько пропущено», без падений.

## Тесты (обязательны)

Чистые функции на фикстурах: тоннаж, e1RM, ISO-неделя через границу года, тренд на плато,
исключение разминочных подходов, агрегация по группам мышц с синергистами.
