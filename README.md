# Gym Coach

Личный помощник по силовым тренировкам: бриф о самочувствии → план на сегодня → ведение подходов →
аналитика прогресса. С iPhone, бесплатно, без сервера.

## Документы

- `docs/prompt.md` — бриф проекта (ТЗ для агента)
- `docs/stack.md` — варианты площадки, рекомендация, скилы и MCP
- `docs/state.md` — где мы сейчас
- `docs/decisions.md` — принятые решения

## Статус

Этап P1: бриф → план → лог подходов → сводка. Работает локально, деплой на Pages — после
авторизации в GitHub.

## Источники

- Иллюстрации и мышечные данные: [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db),
  лицензия Unlicense (public domain), отдача через CDN jsDelivr.
- Методика (прогрессия, объёмы, RPE/RIR): см. скил `.opencode/skills/training-domain`.
