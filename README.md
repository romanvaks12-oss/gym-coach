# Gym Coach

Личный помощник по силовым тренировкам: бриф о самочувствии → план на сегодня → ведение подходов →
аналитика прогресса. С iPhone, бесплатно, без сервера.

## Документы

- `docs/prompt.md` — бриф проекта (ТЗ для агента)
- `docs/stack.md` — варианты площадки, рекомендация, скилы и MCP
- `docs/state.md` — где мы сейчас
- `docs/decisions.md` — принятые решения
